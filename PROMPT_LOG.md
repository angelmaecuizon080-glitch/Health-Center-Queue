**Purpose:** Start building a Health Center Queue Management System with HTML, CSS, and JavaScript.

## 2. Application requirements

> Build my Health Center Queue Management System using HTML, CSS, and JavaScript. Interfaces: both. Design: blue. Data storage: local. Give me complete code and step-by-step instructions

**Requirements captured:**
- Provide both a patient-facing interface and an admin interface.
- Use HTML, CSS, and JavaScript.
- Store application data locally in the browser.
- Provide complete source code and setup instructions.

**Implementation reflected in the current project:**
- `index.html` contains patient registration and the admin dashboard.
- `style.css` provides the interface styling and responsive layout.
- `script.js` implements registration, queue numbering, calling the next patient, completing/skipping patients, searching, resetting, and `localStorage` persistence.

**Note:** The current stylesheet uses a green theme rather than the blue theme stated in the requirements prompt.
